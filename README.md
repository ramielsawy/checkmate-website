# Checkmate Consultants – One-Page Website

Static HTML/CSS site. Open `company.html` in a browser or serve this folder.

## Images

- **Hero:** `assets/hero.webp` (custom).
- **About section:** `assets/about.webp` – replace with your own or use a Freepik image.
- **Problem section:** `assets/revenue-integrity.webp` – replace with your own or use a Freepik image.

Current placeholders are from **Unsplash** (about) and **Pexels** (revenue/analytics), free to use.

### Using Freepik images instead

1. **About (hospitality):**  
   [Luxury hotel reception](https://www.freepik.com/free-photos-vectors/luxury-hotel-reception) or [Luxury hotel lobby](https://www.freepik.com/free-photos-vectors/luxury-hotel-lobby)  
   Download a free image, resize if needed, save as **`assets/about.webp`** (or `.jpg` and update the `src` in `company.html`).

2. **Problem (revenue integrity):**  
   [Revenue chart](https://www.freepik.com/free-photos-vectors/revenue-chart) or [Analytics chart](https://www.freepik.com/free-photos-vectors/analytics-chart)  
   Download a free image, save as **`assets/revenue-integrity.webp`** (or `.jpg` and update the `src` in `company.html`).

Replace the files in `assets/` keeping the same filenames, or change the `src` in `company.html` to match your filenames.
